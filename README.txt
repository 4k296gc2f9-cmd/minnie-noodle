# Minnie Noodle — GitHub Pages fixed version

ສາເຫດຫຼັກຂອງເວີຊັນເກົ່າ: ຮູບອາຫານ/ໂລໂກ້ຖືກຝັງເຂົ້າໃນ HTML ເປັນ Base64 ເຮັດໃຫ້ໄຟລ໌ HTML ໃຫຍ່ຫຼາຍ.
ເວີຊັນນີ້ແຍກຮູບອອກເປັນ `assets/` ແລະບີບຮູບເປັນ WebP ເພື່ອໃຫ້ GitHub Pages ໂຫຼດໄວຂຶ້ນ.

## ອັບຂຶ້ນ GitHub
1. ລົບ/ຍ້າຍ `index 2.html` ອອກ.
2. ອັບ `index.html` ຂຶ້ນທີ່ root ຂອງ repository.
3. ອັບໂຟນເດີ `assets/` ພ້ອມຮູບທັງໝົດ.
4. GitHub Pages → Settings → Pages → Deploy from branch → ເລືອກ branch ທີ່ໃຊ້ ແລະ `/ (root)`.
5. ເປີດ URL ໂດຍບໍ່ຕ້ອງຕໍ່ `?utm_source=...`

ໝາຍເຫດ: ບໍ່ຄວນອັບ `index.html` ຢ່າງດຽວ — ຕ້ອງອັບ `assets/` ໄປພ້ອມກັນ.
